

# Instagram Profile Analysis Dashboard

A Power BI academic project that analyzes Instagram activity data, including engagement, followers, and following behavior.

The project focuses on transforming raw Instagram data into a structured data model and creating an interactive dashboard for identifying activity patterns and trends.

## Dashboard

The report contains two main pages:

### 1. Engagement Analysis
Analyzes engagement activity such as likes, saves, and comments and how engagement changes over time.

### 2. Followers & Following
Analyzes follower and following activity and account relationship patterns.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- JSON
- Data Visualization

## Key Skills Demonstrated

- Data cleaning and transformation
- Data modeling using fact and dimension tables
- Creating relationships between multiple datasets
- KPI development with DAX
- Trend analysis
- Dashboard design and data visualization
- Working with raw JSON data

## Data Privacy

The original dataset was obtained from a personal Instagram data export.
